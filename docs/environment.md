# Environment variables (moved from AGENTS.md)

## Important environment variables

`.env.example` is a partial reference. `engine/config-service.ts` is the canonical source of defaults and validation.

| Variable                      | Default                                                            | Meaning                                                                                                            |
| ----------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| `HELIUS_API_KEY`              | —                                                                  | Required for Solana RPC. In test mode defaults to a dummy value.                                                   |
| `HELIUS_DAS_DISABLED`         | `false`                                                            | Skip the keyed Helius DAS `getAsset` metadata/decimal/price fallback entirely. Use when a free-tier key is exhausted (HTTP 429) and its backoff stalls scan cycles; the keyless standard RPC still resolves decimals for most SPL mints. Gates the shared `fetchHeliusAsset` choke point, so it also suppresses the Helius price and asset paths. |
| `SOLANA_RPC_URL`              | Helius URL if key present                                          | RPC endpoint. Falls back to public Solana RPC if absent.                                                           |
| `WALLET_PRIVATE_KEY`          | —                                                                  | Optional; required only for live trading.                                                                          |
| `PAPER_TRADING`               | `true`                                                             | Simulated positions by default.                                                                                    |
| `SCAN_INTERVAL_MS`            | `600000`                                                           | Time between scan cycles (10 min).                                                                                 |
| `WATCHLIST_POOLS`             | —                                                                  | Comma-separated Meteora DLMM pool addresses.                                                                       |
| `ENABLE_POOL_DISCOVERY`       | `false`                                                            | Opt-in discovery; live mode should use explicit approved watchlist pools.                                         |
| `MIN_POOL_TVL_USD`            | `50000`                                                            | Skip watched pools below this TVL.                                                                                  |
| `DISCOVERY_MIN_TVL_USD`       | `1000000`                                                          | Minimum TVL for opt-in automatic discovery.                                                                         |
| `MARKET_SCAN_ENABLED`         | `false`                                                            | Master switch for universe-driven trading: the watchlist becomes optional and the top-K ranked pools of the Meteora universe are traded through the normal gates (see Market-scan mode). |
| `MARKET_SCAN_REFRESH_INTERVAL_MS` | `1800000` (30 min)                                              | How often the universe gate re-runs and the active pool set is rebuilt (min 60 s).                                   |
| `MARKET_SCAN_UNIVERSE_PAGES`  | `3`                                                                | Top-N pages (1000 pools each) of the TVL-ranked universe fetched per refresh (1–10).                                 |
| `MARKET_SCAN_MIN_TVL_USD`     | `50000`                                                            | Minimum TVL for the market gate (lowered so the small-but-hot runners clear it).                                     |
| `MARKET_SCAN_MIN_FEE_APR`     | `100`                                                              | Minimum annualized fee/TVL percent for the market gate (fees24h×365/tvl×100) — only real-yield pools enter the active set. |
| `MARKET_SCAN_RUNNER_ENABLED`  | `false`                                                            | Market-runner lane master switch: market-scan pools whose MEASURED (datapi) fee APR clears the runner floor enter with the LAUNCH posture (time-boxed, dip-anchored, scale-in) instead of the flat normal posture. Paper-first. |
| `MARKET_SCAN_RUNNER_MIN_FEE_APR` | `500`                                                           | Fee APR floor (fees24h×365/tvl×100, datapi-measured only — modeled gecko/heuristic fees never classify) for the runner posture. |
| `MARKET_SCAN_RUNNER_MIN_DRIFT_BINS` | `-8`                                                          | Runner admission drift floor (bins): a runner whose net active-bin drift sits below this is a sustained decliner, not a dip — the lane rejects it with an audited `[runner-drift-gate]` decision even when its APR is enormous. Unknown drift (no bin history) fails open; `0` disables the floor. Default mirrors the normal-lane `MARKET_SCAN_MAX_NEGATIVE_DRIFT_BINS`. |
| `MARKET_SCAN_ROTATION_ENABLED`| `false`                                                            | When the portfolio is full and a market runner clears the lowest-APR held position by `MARKET_SCAN_ROTATION_APR_MULT`, exit that held position (confidence 1) so the freed slot admits the runner next cycle — rotating existing exposure INTO high-yield pools, never adding positions. |
| `MARKET_SCAN_ROTATION_APR_MULT` | `5`                                                             | Minimum candidate-APR / worst-held-APR multiple before a rotation EXIT fires (compared on NET fee APR — capture share, conversion + harvest costs applied to both sides). |
| `MARKET_SCAN_RUNNER_CONFIRM_CYCLES` | `2`                                                       | Runner admission + rotation superiority must persist across this many consecutive above-floor APR observations (per-pool ring in the metadata table) — a single-cycle fee spike never qualifies a pool. |
| `MARKET_SCAN_ROTATION_ARM_MS` | `1800000`                                                     | TTL for the rotation arm: the incumbent EXIT executes only while the arm is fresh and the runner still qualifies (cancel-and-preserve when the challenger evaporates). |
| `YIELD_REGRESSION_EXIT_PCT` | `0.5`                                                          | Deterministic EXIT when a tracked position's MEASURED (datapi) fee APR falls below its entry-time APR × this fraction — the engine self-heals out of flat majors without waiting for a challenger. Launch positions excluded (own lifecycle). |
| `FEE_CAPTURE_CONVERSION_COST_PCT` | `0.05`                                                   | Conversion-cost haircut applied to expected fees in the net-fee rotation model. |
| `FEE_CAPTURE_HARVEST_COST_USD` | `0.01`                                                      | Per-harvest cost (USD) subtracted from expected fees in the net-fee rotation model. |
| `HARVEST_MIN_NET_USD` | `1`                                                              | Economic harvest gate: skip an on-chain fee claim when the pending net fees are below this floor (rule: never spend $0.80 to realize $1.00). Skipped claims do NOT re-arm the interval — they retry next scan. Pending amount unavailable -> fail open (claim anyway). Paper accrual unaffected (no tx cost). |
| `HARVEST_MAX_COST_PCT` | `0.15`                                                          | Harvest gate: skip the claim when the estimated tx cost exceeds this fraction of gross pending fees. |
| `HARVEST_TX_COST_USD_EST` | `0.005`                                                      | Estimated on-chain claim tx cost (USD) used by the harvest gate. |
| `ALLOW_TRANSFER_FEE_TOKENS` | `false`                                                      | G5 transfer-tax screen: reject any pool with a leg whose Token-2022 transfer-fee extension is enabled (adapter mint parse + market gate + the shared safety screen). Set true only to deliberately allow them. |
| `TOKEN_FAILURE_BLOCK_MS` | `3600000`                                                     | G6 token-level circuit breaker: a genuine live EXIT failure on a pool blocks new ENTERs into ANY pool holding either of that pool's tokens for this window (metadata `token_block:<mint>` stores the block EXPIRY). Metadata read/write errors fail open. |
| `RUG_EXIT_LOSS_PCT` | `0.5`                                                     | Rug detection: a closed position whose realized PnL ≤ -(depositedUsd × this) marks a rug/drained token and arms `token_rug_block:<mint>` for its NON-STABLE legs. Clamped [0.05, 1]. |
| `RUG_TOKEN_BLOCK_MS` | `604800000` (7 days)                                                     | How long a rug exit blocks re-entry into the drained token. Distinct from `TOKEN_FAILURE_BLOCK_MS` so a rugged token stays blocked far longer than a transient exit failure. Clamped [1h, 30 days]. |
| `MIN_YIELD_EXIT_AGE_MS` | `43200000` (12h)                                                     | Economic-exit maturity gate (forensics-driven): the fee/IL < 0.5 and yield-regression EXITs do NOT fire until a position is this old — the paper forensics showed 33-minute median holds exiting at a loss on temporary IL that reversed, arming cooldowns that starved ENTERS. Capital-protection exits (W15, IL dominance, dust, TVL drop, trailing stop, lifecycles) AND the volume-auth EXIT (a measured pool property, not fee-accrual-dependent) stay age-free. |
| `FEE_STARVATION_AGE_MS` | `259200000` (72h) | Fee-starvation exit: a position OLDER than this with combined swap fees + rewards below `FEE_STARVATION_MIN_FEES_USD` is dead capital (mark held at entry, zero yield, slot occupied) — closed regardless of measured-fee status. Ledger-verified: zero closes exceed 53h, so the default has zero backtest churn. `0` disables. |
| `FEE_STARVATION_MIN_FEES_USD` | `1` | Fee floor below which an old position counts as starved. |
| `MARKET_SCAN_MAX_NEGATIVE_DRIFT_BINS` | `-8`                                              | [drift-gate] momentum guard: a normal/market-lane ENTER is rejected when the pool's net active-bin drift sits below this floor (cascading price). Clamped at 0 — a positive floor would reject every normal ENTER. The drift is the last-minus-first active-bin over the in-memory bin-history ring (capped at max(VOLATILITY_LOOKBACK_SNAPSHOTS, OOR_RECOVERY_LOOKBACK_CYCLES, 2), not the volatility lookback alone). Runner entries (dip-ladder fills ON dips) and launch-lane entries (young pools, no history) are exempt. |
| `ENTRY_MOMENTUM_CONF_BOOST` | `0.05`                                                     | Max confidence boost from positive active-bin drift in the normal-ENTER confidence (`min(0.5 + feeIl×0.05 + clamp01(drift/ref)×boost, 0.85)`) — a feeIl ~2 pool with real upward momentum crosses the 0.65 floor without lowering the threshold for static pools. |
| `ENTRY_MOMENTUM_REFERENCE_BINS` | `20`                                                   | Drift (bins) at which the momentum boost/score term saturates. |
| `ENTRY_MOMENTUM_SCORE_WEIGHT` | `0.15`                                                   | Weight of the bounded momentum term in `weightedEntryScore` (positive drift only; negative contributes 0). |
| `TAKE_PROFIT_ENABLED` | `false`                                                      | Normal-lane take-profit (winrate): at ENTER, build a single-rung TP ladder (`TAKE_PROFIT_PCT` above entry); a deterministic `[tp-target]` EXIT (confidence 1) fires when the price reaches the rung — BEFORE the loss-side exits. Paper-first. |
| `TAKE_PROFIT_PCT` | `0.15`                                                         | TP rung distance above the entry price. |
| `BACKTEST_TOLERATE_EMPTY_BINS` | `true`                                                 | Backtest replay fidelity: empty-bin snapshots (the paper DB stores `bins:[]` for every row) degrade bin-utilization to UNKNOWN (skip the requirement) instead of 0 (reject every tick). False = parity with the pre-fix replay. |
| `VOLATILITY_LOOKBACK_SNAPSHOTS` | (existing)                                             | Recent-bin window length — the drift signal's lookback. |
| `MARKET_SCAN_TOP_K`           | `30`                                                               | How many top-ranked market pools are actively scanned each cycle (1–200).                                           |
| `MARKET_SCAN_MAX_POOLS`       | `60`                                                               | Hard cap on market-scan pools in the active scan set.                                                               |
| `MARKET_SCAN_MIN_HOLDERS`     | `1000`                                                             | Minimum holders for a non-stable, non-SOL leg to pass the market gate pre-filter. Also a HARD, verification-blind floor for market candidates — a "verified" token with dust holders is still a single-cluster rug setup. Unknown holder count fails open (the per-pool screen still gates ENTER). |
| `MARKET_SCAN_REQUIRE_RENOUNCED_MINT` | `true`                                                    | Hot-lane (market/runner) hard gate: reject a candidate when a non-stable, non-SOL leg still has a live mint authority (not renounced) — dev can mint+dump. Checked per pool from on-chain mint authorities in the safety screen (absent from the Data API list payload). Stables + SOL exempt, as is a Data-API-verified leg on a pool clearing `MARKET_SCAN_VERIFIED_EXEMPT_MIN_TVL_USD` (tokenized equities and bridged majors retain mint authority by design). Advisory in the standalone token-risk overlay; HARD for the market lane. |
| `MARKET_SCAN_VERIFIED_EXEMPT_MIN_TVL_USD` | `100000`                                              | Verified-scale exemption for the renounce gate: a live-mint-authority leg is exempt when Data-API-verified AND pool TVL clears this. `0` restores the strict verification-blind binary. |
| `MARKET_SCAN_MIN_POOL_AGE_HOURS` | `24`                                                         | Hot-lane rug-factory age floor: reject a market/runner candidate younger than this many hours. Brand-new pools are the ruin tail; the runner lane trades proven-age pools. Unknown age fails open. `0` disables. |
| `MARKET_SCAN_MIN_BIN_STEP`    | `2`                                                                | Skip pools with finer bins (ultra-fine bins churn).                                                                 |
| `MARKET_SCAN_MAX_BIN_STEP`    | `200`                                                              | Skip pools with wider bins (fee dilution).                                                                          |
| `VOLUME_AUTH_THRESHOLD`       | `0.70`                                                             | Minimum volume authenticity score.                                                                                 |
| `STABLECOIN_MINTS`            | USDC/USDT/PYUSD                                                    | Trusted stablecoin mints exempt from freeze-authority screening (allowlist). Empty (`=""`) disables the allowlist entirely; entries are pubkey-validated fail-closed. |
| `FREEZE_SMART_SCREENING`      | `false`                                                            | Pass untrusted freeze-enabled pools to the quality pipeline (warning memory + audit note) instead of rejecting.    |
| `JUPITER_TOKEN_RISK_ENABLED`  | `true`                                                             | Enable the Jupiter/Data-API token-risk overlay for freeze adjudication and the ENTER token-risk gate.              |
| `JUPITER_TOKEN_RISK_CACHE_TTL_MIN` | `30`                                                            | Minutes a Jupiter token-risk signal is cached before refresh (min 1).                                             |
| `IL_PROTECTION_ENABLED`       | `true`                                                             | Master switch for the entry fee/IL floor and the IL-dominance fast EXIT. See IL protection.                        |
| `MIN_FEE_IL_RATIO`            | `1.2`                                                              | Minimum fee/IL ratio to HOLD; also a hard ENTER floor when IL protection is on (entry fees must beat estimated IL). |
| `IL_DOMINANCE_EXIT_FACTOR`    | `2`                                                                | IL-dominance EXIT fires when IL (USD) exceeds cumulative-fees × this factor (min 1).                               |
| `IL_DOMINANCE_MIN_USD`        | `5`                                                                | Minimum IL (USD) before the IL-dominance fast EXIT may fire (min 0).                                              |
| `CONFIDENCE_THRESHOLD`        | `0.65`                                                             | Minimum confidence to act.                                                                                         |
| `STOP_LOSS_PCT`               | `0.15`                                                             | Drawdown that blocks HOLD/REBALANCE.                                                                               |
| `TRAILING_STOP_PCT`           | `0.10`                                                             | Drawdown from peak that triggers EXIT.                                                                             |
| `OOR_COOLDOWN_MS`             | `14400000`                                                         | Cooldown after an OOR (volatility) or low-yield EXIT; blocks re-entry on the pool. Also the static/floor ceiling for the fee-density-scaled low-yield cooldown. |
| `REPEAT_OOR_COOLDOWN_MS`      | `43200000`                                                         | Escalated cooldown once a pool's OOR exit count reaches `MAX_OOR_COOLDOWN_EXITS`.                                  |
| `MAX_OOR_COOLDOWN_EXITS`      | `3`                                                                | OOR exits at which the pool cooldown escalates to `REPEAT_OOR_COOLDOWN_MS` (min 1).                                |
| `MIN_REENTRY_COOLDOWN_MS`     | `7200000` (2h)                                                     | Same-pool re-entry churn throttle: arms a pool cooldown on EVERY exit (not just OOR/low-yield), so an exited pool is NOT re-admitted for at least this long regardless of exit type (trailing-stop/rotation/TP/yield-regression/W15 exits previously armed nothing). Fixes the pathological churn class live-forensiced 2026-08 (a hot pool exiting and re-admitting every ~10 min — 5rCf1: 221 round-trips/2 days, −$163 cost drag at ~50% win rate). OOR/low-yield keep their own (possibly longer) cooldown. `0` disables. |
| `FEE_DENSITY_COOLDOWNS`       | `true`                                                             | Scale the low-yield exit cooldown by Data-API-measured fee density (`fees24hUsd / tvlUsd` per day — modeled gecko/heuristic fees excluded, see stats sources): high-density pools re-enter sooner, thin pools stay cooled down for the full static duration. Off or unmeasured → static `OOR_COOLDOWN_MS`. |
| `FEE_DENSITY_COOLDOWN_MIN_MS` | `3600000`                                                          | Cooldown floor for a high-fee-density low-yield exit (1 h default, min 0).                                          |
| `FEE_DENSITY_HIGH_PCT`        | `0.005`                                                            | Fee density (fees/TVL per day) at/above which the low-yield cooldown hits `FEE_DENSITY_COOLDOWN_MIN_MS`. Must exceed `FEE_DENSITY_LOW_PCT` (inverted band falls back to defaults for both). |
| `FEE_DENSITY_LOW_PCT`         | `0.0005`                                                           | Fee density (fees/TVL per day) at/below which the low-yield cooldown stays at the static `OOR_COOLDOWN_MS`; between the thresholds the duration is linearly interpolated. |
| `MAX_OPEN_POSITIONS`          | `3`                                                                | Concurrent positions cap (total, portfolio-wide).                                                                    |
| `MAX_POSITIONS_PER_POOL`      | `2`                                                                | Max simultaneous positions on one pool (Wave 10). Aggregate per-pool exposure stays bounded by `MAX_PER_POOL_ALLOCATION_PCT`. Set `1` for legacy single-position behavior. |
| `MAX_ENTRY_SIZE_USD`          | `500`                                                              | Hard USD ceiling per conservative entry (the sizing formula's cap term). Raise for high-frequency rotation profiles. |
| `MAX_PER_POOL_ALLOCATION_PCT` | `0.4`                                                              | Max portfolio share for one pool (aggregate across all of that pool's positions).                                     |
| `SQLITE_DB_PATH`              | `~/.local/share/prism/prism.db` (bundled) or `./prism.db` (source) | SQLite database path.                                                                                              |
| `ENABLE_SNAPSHOT_CAPTURE`     | `false`                                                            | Store full bin-array detail in per-cycle snapshots (paper only). Lightweight per-cycle snapshot rows are always persisted — TVL velocity and IL drift need the history. |
| `SNAPSHOT_RETENTION_DAYS`     | `14`                                                               | Days of `pool_snapshots` history to keep; older rows are pruned once per day (first cycle prunes immediately). The Rust host mirrors the same retention onto `prismd_pool_history`, pruning on every write instead of daily. |
| `METEORA_DATA_API_URL`        | `https://dlmm.datapi.meteora.ag`                                   | Base URL for the Meteora Data API used to enrich pool TVL/volume/fees. On failure the engine falls back to GeckoTerminal, then the heuristic (last resort), with a warning.                              |
| `GECKO_TERMINAL_ENABLED`      | `true`                                                             | Master switch for the GeckoTerminal secondary pool-stats source (tried when the Data API is down). Set `false` to skip gecko and fall straight to the heuristic. Pinned `false` in the test fixture so program tests never touch the network. |
| `GECKO_TERMINAL_API_URL`      | `https://api.geckoterminal.com/api/v2`                            | Base URL for the GeckoTerminal public API (keyless, 30 req/min); the `/networks/solana/pools/{address}` path is appended in code. Real volume/TVL; fees = real volume × the pool's binStep-derived base fee (`pool_fee_percentage` is null for CL pools). Requests are paced ≥2.1s apart (28/min, under the 30/min limit); 429s still fail through to heuristic. |
| `DLMM_CACHE_TTL_MS`           | `300000` (5 min)                                                   | Per-pool DLMM client cache TTL (ms, 60s–1h). Longer skips `DLMM.create` re-reads (1–2 Solana RPC per pool); lbPair immutable fields make extension low-risk. Paper-first via env. |
| `PYTH_ENABLED`                | `true`                                                             | Master switch for the Pyth Hermes price-feed poller (parallel low-latency USD oracle). **SERVICE-ONLY**: the `PythPriceService` layer is available in `buildLayer` but NO decision/risk code consumes it yet — consumer wiring (trailing-stop marks, HODL benchmark, hedge marks) is a deliberate follow-up. |
| `PYTH_API_KEY`                | `""`                                                               | Optional Hermes API key, sent as an `Authorization: Bearer <key>` header (never a query param — verified against docs.pyth.network). Empty = public keyless access, which Pyth **ends right after 2026-07-31** (docs.pyth.network also cites 2026-08-18); a key is required after that. Get one from the Pyth Terminal (docs.pyth.network → price feeds → Hermes API keys). |
| `PYTH_MAX_STALENESS_MS`       | `60000`                                                            | Max age of a Hermes `publish_time` before the price is treated as unknown (→ null, min 5000). |

SOL/USDC/USDT feed IDs are built in (verified against the official feed list) and arbitrary feed IDs are accepted. |

| `ENTRY_STRATEGY_TYPE`         | `spot`                                                             | DLMM deposit distribution for new positions: `spot` \| `curve` \| `bidask` \| `auto` (auto picks per pool from volatility/trend; see Entry strategy shapes). |
| `ENTRY_RANGE_HALF_WIDTH_BINS` | `0`                                                                | Static baseline range half-width (bins each side) for entries/rebalances. `0` = binStep-tiered default (25/20/15). Bounded by `MAX_REBALANCE_RANGE_BINS`; see Volatility-adaptive range width. |
| `VOLATILITY_ADAPTIVE_RANGES`  | `true`                                                             | Scale the range half-width by measured realized volatility (high vol → wider, calm → narrower); on by default, set `false` for static widths. Cold start falls back to the baseline; see Volatility-adaptive range width. |
| `MIN_RANGE_HALF_WIDTH_PCT`    | `5`                                                                | Price-coverage floor for the range half-width (percent each side). The binStep-tier baseline (25/20/15) caps fine-binStep pools (SOL/USDC binStep 4) at ~±1-2% price coverage, which cannot hold a 40%+ swing — the pool bleeds unbounded out-of-range IL (honest backtest: SOL/USDC −$1158 net / IL ~$1157 on a fixed 25-bin range). Influenced by each pool's binStep (`(1+binStep/1e4)^bins ≥ 1+pct/100`), so coarse pools are untouched (their baseline already spans 5-13%). Bounded by the `MAX_REBALANCE_RANGE_BINS` half-cap and clamped to [0,50]; set `0` to disable. The robust, model-independent win is the IL collapse to ~$40; the fee upside is bounded by a concentration-aware dilution (a range k× wider captures ~1/k of active-bin fees — the optimistic width-independent fee model overstates it ~5×). |
| `IDLE_REDEPLOY_ENABLED`       | `false`                                                            | Master switch for the per-cycle idle-capital auto-redeploy gate (opt-in). "Idle" = USDC wallet balance (live) / `PAPER_PORTFOLIO_USD` minus open positions (paper). Never overrides `MAX_OPEN_POSITIONS` / `MAX_POSITIONS_PER_POOL` / `MAX_PER_POOL_ALLOCATION_PCT`. At most one redeploy ENTER per cycle. |
| `IDLE_REDEPLOY_THRESHOLD_USD` | `500`                                                              | Idle capital (USD) that must sit undeployed before the redeploy pass acts (min 0).                                   |
| `IDLE_REDEPLOY_MAX_SIZE_USD`  | `2000`                                                             | Hard ceiling (USD) on a single redeploy entry, on top of the per-pool allocation the risk tail re-applies (min 0).   |
| `REALIZED_PNL_HALT_ENABLED`   | `false`                                                            | Rolling realized-PnL loss halt master switch. EXIT/REBALANCE stay free (capital protection + position management never blocked). The anti-bleed breaker for high-frequency churn lanes whose swap/spread cost + IL exceeds fee capture (live forensics: 50% win rate at −2.7% ROI on a pool churned hundreds of times/day). Recomputed each cycle from the DB; auto-lifts on recovery. Fail-open: empty/absent realized history never halts. |
| `REALIZED_PNL_HALT_WINDOW`    | `100`                                                              | Number of most-recent closed positions whose realized PnL is summed for the rolling halt (min 1). |
| `REALIZED_PNL_HALT_THRESHOLD_USD` | `-20`                                                          | USD threshold below which the rolling realized-PnL sum trips the halt.   |
| `POOL_PNL_KILL_SWITCH_ENABLED` | `false`                                                            | Pool-local anti-bleed breaker. When enabled, the latest N known realized closes for each pool netting below the threshold arm that pool's persisted ENTER cooldown; EXIT/REBALANCE remain free. |
| `POOL_PNL_KILL_SWITCH_MIN_CLOSED_POSITIONS` | `10`                                                    | Minimum known realized closes for one pool before its local PnL kill switch can trip. |
| `POOL_PNL_KILL_SWITCH_THRESHOLD_USD` | `-15`                                                        | Trailing per-pool realized-PnL threshold; a sum strictly below it trips the local cooldown. |
| `POOL_PNL_KILL_SWITCH_COOLDOWN_MS` | `172800000` (48h)                                           | Duration of the pool-local ENTER cooldown after a confirmed trailing-PnL breach. |
| `FARM_REWARDS_ENABLED`        | `true`                                                             | Master switch for periodic LM farm reward claims (live only). Scoring stays farm-aware regardless. See Farm rewards. |

| `PRISM_CONFIG_DIR`            | `~/.config/prism`                                                  | Override the shared credentials and config directory.                                                              |
| `PRISM_FEEDBACK_OPT_OUT`      | `false`                                                            | Disable automatic feedback.                                                                                        |
| `ALERTS_ENABLED`              | `true`                                                             | Master switch for proactive Telegram alerts (engine-side). Delivery still requires registration + Telegram link.   |
| `ALERT_COOLDOWN_MINUTES`      | `120`                                                              | Per-rule (alert type + pool) cooldown between pushed alerts. Persisted in SQLite metadata.                         |
| `ALERT_FEE_MILESTONE_USD`     | `10`                                                               | USD step between cumulative-fee milestone alerts.                                                                  |

In test mode (`NODE_ENV=test` or `VITEST=true`), missing `HELIUS_API_KEY` defaults to `test-helius-key` and `SOLANA_RPC_URL` defaults to `https://example.com`.
